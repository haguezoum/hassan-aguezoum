SVG source: https://www.tech-stack-icons.com/

The original nine logos and the NestJS, Swagger, Vue.js, Git, Bash, and C++ logos were
extracted from the website's rendered dark-variant icon images on 2026-10-05.
Other existing SVGs in this folder are preserved. The tech-stack-icons package is not installed or required.
Names match the source catalog. Logos remain the property of their owners.

The animation derives its inventory from project tags and WORK/EDUCATION techSkills. Add a local SVG and an
alias in src/lib/tech-stack.ts to use a library logo for a new technology.
Unmapped tags use a text mark rather than an unrelated brand logo.
